How comparisons work

Each UTC day's newest finished run; each prompt counts once. Day-over-day changes compare shared, unchanged prompts of the same answerers. Grey changes have a 95% interval covering zero. Set changes are annotated; a change in how answers are asked or graded restarts comparisons.

Dots: daily rates. Line: rolling average. Shading: 95% band across prompts (questions like these). Hover a day for sampling uncertainty on that day's fixed prompts. Vertical lines mark set or method changes; triangles mark proposed or accepted fixes.
