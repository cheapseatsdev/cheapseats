# Unscheduled prompt research

These 13 questions are outside `prompt-sets/` and are not loaded, scheduled or included in the
active fix list. Nine unbranded questions explore starter-market hypotheses; four known-brand
questions cover peer comparisons, developer-tool fit and the event-driven running-cost audit.
They keep their original IDs and wording for the same research question. The 56 retired questions
are listed separately in [the retirement registry](../prompt-sets/retired-ids.txt).

Before testing, select one hypothesis from the TOML comments and name the specific positioning,
onboarding or product decision it could change. Identify what evidence could support a useful
quick win or suggestion. If there is no credible action, do not run it. Existing content and a
possible brand mention do not establish demand or justify recurring calls.

For an experiment, choose answerers, samples and budget explicitly and use at most two deliberately
budgeted evaluation occasions before reviewing. Promote only with target-buyer evidence and an
ongoing decision. A cost audit is triggered by a material setup, model-access or budget change;
check claims against actual configuration and usage, then stop after verifying any corrections.
These are review rules, not automatic scheduler limits.

Use a scratch config with only the selected questions for research; validate with
`cheapseats check -no-jev` and inspect `cheapseats plan` before any run. Keep a branded question
in a set with ID `head-to-heads`. Do not copy the whole research file over the active file: that
would replace the curated suite and activate every question in that file. Promotion of the same
question preserves its identity; a genuinely different buyer need gets a new ID.

General AEO/GEO lessons, unsupported-engine requirements, enterprise procurement and agency
reporting did not earn a place in this starter suite. A missing capability is not a copy fix.
An analyst-generated page suggestion is not proof the page should exist.
